# Be Vietnam Pro for Open Graph

Copyright 2021 The Be Vietnam Pro Project Authors. Licensed under SIL OFL 1.1 (see OFL.txt).
Source: https://github.com/bettergui/BeVietnamPro (Google Fonts distribution).

The regular (400) and extra-bold (800) TTF files were reconstructed offline from the existing Next.js Google Fonts cache, combining the Latin, Latin Extended and Vietnamese subsets with FontTools. No outlines or font family names were changed.

These local assets are read by `src/app/opengraph-image.tsx`; image generation never downloads fonts. ImageResponse supports TTF, but not the WOFF2 files used by next/font in the browser.
